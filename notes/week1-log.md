5日目 学んだこと: ブランチとプルリクエスト

- ブランチは、mainのある時点から分かれた、独立した履歴の線(コミットを指す目印)。
- pushで、その枝をGitHubに送り、プルリクエストで、「この枝を、GitHub上のmainに取り込んでよいか」を確認・依頼する。
- マージで、実際に取り込み、手元のmainは git pull で追いつく。
- ローカルにしかないブランチは、pushしないとGitHubには認識されない。
